# Code w/ friendz! downloads

Official desktop installation packages for Windows and macOS. Application source code lives in a separate private repository. This repository contains releases only.

Download page: https://cwf-downloads.vercel.app

The 0.8.0 demonstration release is unsigned on Windows and has no Apple notarization. Meeting files and terminals run on the organizer’s computer; account and nickname data use the shared service. See each release for verification details and SHA-256 checksums.
